# Final output products

The one-shot workflow records the full user input set and renders two final diagnostic products after the branch-specific Fourier calculation has completed.

For `field-id = N`, files are written under `Freq_Time_Domain_Result_N/`.

- `run_parameters.json`: exact user inputs accepted by `scripts/run_pipeline.py`, plus the detected macro-image type and the two derived Jacobian eigenvalues.
- `amplification_comparison.csv`: numerical frequency-domain result produced by the branch-specific Fourier helper.
- `minimum_amplification_comparison.png`, `saddle_amplification_comparison.png`, or `maximum_amplification_comparison.png`: the final full-vs-macro-only amplification plot, annotated with the input parameters.
- `stellar_field_realization.png`: the actual microlens realization generated by the solver. Positions are read from `MicroLensCoorXY_*.bin`, masses are read from `Lens_Mass_*.bin`, and marker color represents microlens mass. The plotting step never generates or resamples lenses.

The renderer is deliberately downstream of the numerical calculation. It reads existing solver/Fourier outputs and does not modify the C++ adaptive algorithm, random streams, time-delay calculation, component decomposition, or Fourier integration.
